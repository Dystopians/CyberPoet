# CyberPoet · 现代诗歌模型训练

在 Qwen3-14B 上训一个写中文现代诗的模型。**文学性只由项目主人盲选裁定，
模型永不参与评审。** 本仓库存文档、脚本与配置，不存诗歌正文、训练数据与模型权重
（版权原因见文末）。

按主人 101 条批注重构）**，活模型 **M4**，M5/M6 已配置待训。

本周最重要的一件事：**「全参路线不行」这个结论被推翻了**——
逐权重尸检发现全参臂 79.56% 的参数逐比特未变，
是 `pure_bf16`+LR1e-5 的数值地板，不是方法问题（[尸检报告](docs/证据链/11-全参失败根因尸检.md)）。

## 三条最硬的结论

1. **语料的质 > 量**：修复 555 首损坏文本 → 主人盲选 22:7（p=0.008）；
   语料翻倍 → 14:8（p=0.286，方向正但红利递减）。
2. **罚的是执行，不是特征**：复沓装置在人机对局里被罚（65:26，p<0.001），
   在纯人对局里反而受偏爱——**禁止**对修辞特征做门控或负加权，
   治理靶点永远是执行水平。
3. **可数的「质感合格线」**（实词密 + 句读齐 + 长句承重）在诗的层级预测主人的票
   （样本外 p=0.002），但在诗人层级失效——**它是合格线，不是冠军线**。

## 仓库里没有什么，为什么

语料是在世/版权期诗人的作品（洛夫、海子、昌耀、多多、张枣、商禽、痖弦、陈舸……
共 66 家），本仓库是公开的。因此以下一律不入库，只留在服务器：

- 诗歌正文、语料快照、微调数据（其答案就是原诗）
- 由原诗改写而来的草稿（衍生内容）
- 适配器与模型权重

**一个例外，与它的边界**：`labeler/*.html` 四份标注页可以入库——
里面只有模型生成的诗，与语料的最长逐字重合实测为 0 字。
但 08-29 查出**阅读包页面越过了这条界**（附了 30 首真人原作供对照），已移除。
今后凡页面含「语料原作对照」区段的，一律不入库。

## 三条不能忘的规矩

1. **不用模型评价文学性。** 曾经的 AI 评审判「基座胜 31/36」，主人实读后的判断与之相反
   （base 对一切微调臂 2 胜 70 负，p=7×10⁻¹³）。文学判断权 100% 属于人。
2. **可数指标只排序，不做门。** 机械分数当准入门会杀掉主人喜欢的诗
   （同模型采样上 quality_score 准确率仅 49%）。
3. **训练跑完 ≠ 训练发生。** loss 有数字、生成不是乱码，都不能证明模型真的学到了。
   新训练方式首次落地必跑 `scripts/audit/weigh_fullparam.py`，零变化率 >50% 立即停链。
   （这条规矩是 08-29 那次尸检用五个 GPU 小时换来的。）
