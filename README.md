# CyberPoet · 现代诗歌模型训练

在 Qwen3-14B 上做中文现代诗写作模型。本仓库存**文档、脚本与配置**，
不存诗歌正文、训练数据与模型权重（原因见下）。

## 一句话现状（2026-08-25）

前两轮微调（v1、v2）都因训练数据自相矛盾而失败；查清并修复了五处缺陷后，
换到「继续预训练 + 修复版微调」这条路线，第一次拿到项目主人认可的文学质量提升。

## 仓库里没有什么，为什么

语料是十二位诗人（洛夫、海子、昌耀、穆旦、多多、张枣、商禽、痖弦、卞之琳、
陈舸、冯至、王炜）的作品，**仍在版权期内**，本仓库是公开的。因此以下内容一律
不入库，只留在服务器与私有存储：

- 诗歌正文、语料快照、微调数据（其答案就是原诗）
- 由原诗改写而来的草稿（属于衍生内容）
- 适配器权重（自版权文本训练而来，且体积大）

`.gitignore` 已按此设置。需要交换大文件时走私有中介（Google Drive），不直接传输。

## 两条不能忘的规矩

1. **不用模型评价文学性。** 项目里既有的一切文学结论都出自 AI 评审，
   而 AI 评审判定「基座胜 31/36」；项目主人实际读过之后的判断与之相反。
   只报可数的东西，诗交给人读。
2. **机械分数只用于排序，不用作准入门。** 实测：主人明确喜欢的两首诗，
   一首被质量分（−28.5，门槛 −8.0）丢弃，一首被行长筛排除。
