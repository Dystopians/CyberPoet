# CyberPoet · 现代诗歌模型训练

在 Qwen3-14B 上训一个写中文现代诗的模型。**文学性只由项目主人盲选裁定，
模型永不参与评审。** 本仓库存文档、脚本与配置，不存诗歌正文、训练数据与模型权重
（版权原因见文末）。

## 四条最硬的结论

1. **语料的质 > 量**：修复 555 首损坏文本 → 主人盲选 22:7（p=0.008）；语料翻倍 → 14:8；
   pt8 代再加量 → 8:13、「都不要」55%。量到 pt8 见顶。
2. **罚的是执行，不是特征**：复沓装置在人机对局里被罚（115:55，p<0.001，八卷合并），
   在纯人对局里反而受偏爱——**禁止**对修辞特征做门控或负加权。
3. **可数的「质感合格线」**（实词密 + 句读齐 + 长句承重）在诗的层级预测主人的票
   （样本外 p=0.002），在诗人层级失效——它是合格线，不是冠军线。
4. **DPO 的参考模型接错了**：代码、配置、日志、权重比对四条线一致；开局奖励 +8～+10 是既有差距不是学到的，
   大半偏好对梯度接近 0。改回桥后短于 60 字的诗 52 → 13/198，但干预臂几乎未训，「参考对了就不拽短」待剂量实验。

## 三条不能忘的规矩

1. **不用模型评价文学性。** 曾经的 AI 评审判「基座胜 31/36」，主人实读后的判断与之相反
   （base 对一切微调臂 2 胜 70 负）。文学判断权 100% 属于人。
2. **可数指标只排序，不做门。** 机械分数当准入门会杀掉主人喜欢的诗
   （同模型采样上 quality_score 准确率仅 49%）。09-16 复核发现装配按质感排序取第一首，实际做了门——待主人裁。
3. **训练跑完 ≠ 训练发生；配置对了 ≠ 参考对了。** 新训练方式首次落地必跑权重差分
   （09-02 口径：零变化率 >70% 且 ‖Δ‖/‖W‖ <5e-4 才是未训签名）；每次 DPO 前必查参考模型是什么
   （LoRA 下「关 adapter」= 裸底座，须先合并桥）。两条规矩各用了几个 GPU 小时换来。
