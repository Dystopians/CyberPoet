# 比喻超标与书面化漂移的根因（2026-08-30 晚，v9 作答前）

上一轮只量了分布，没查因。本篇查因。两条都定位到了，都能用数字算平。

## 一、比喻超标：偏好数据里 60% 的行，指向的是一个**两倍于语料**的目标

`dpo_train_v4.json` 484 行不是同质的，是两批东西缝在一起：

| 批次 | 行数 | chosen 侧是真人原作的比例 | chosen 比喻/万字 | rejected 比喻/万字 |
|---|---|---|---|---|
| **继承自 v1**（早期臂间对决，主人未参与） | 290 | 32 行 = **11%** | **52.9** | 80.7 |
| **主人盲选新建**（v5–v8 金标） | 194 | 128 行 = **66%** | **26.3** | 35.5 |

参照：真人诗 **25.0** · pt8 训练料 **25.8**

- 主人票新建的那 194 行，chosen 是 **26.3**——**和真人诗、和训练语料完全对齐**。
  主人的票本身带的信号是对的。
- 继承的 290 行，chosen 是 **52.9**——两倍。因为那批是 AI 打 AI，
  chosen 侧只有 11% 是真人原作，**它里面根本没有一首语料水平的诗可指**。
  DPO 学的是相对偏好，(52.9 打赢 80.7) 这种对，**再训多少轮也不可能把模型拉到 25**。

两批加权：290×52.9 + 194×26.3 → chosen 整体 **42.0**。

**账算平了：**

| | 比喻/万字 |
|---|---|
| 真人诗 / pt8 训练料 | 25.0 / 25.8 |
| dpo_v4 的 chosen 侧（实际目标） | **42.0** |
| M4（用 dpo v1，chosen=52.9） | 36.9 |
| **M5（= M4 + dpo_v4，唯一变量）** | **46.3** |
| M6（pt8 新语料 + dpo_v4） | 37.9 |

**M5 是决定性证据**：它与 M4 只差偏好数据，比喻率 36.9 → **46.3**，
即 DPO **确实起作用了，而且精确地把模型推向了 42.0 那个目标**。
不是"模型学不会"，是**我们给的靶子本身就在两倍处**。
M6 之所以回到 37.9，是 pt8 的新语料在往回拽，抵消了一部分。

同一批数据在抽象词上也是同样结构（逐对检验 chosen 抽象更少 138 对 / 更多 105 对，p=0.040，
方向对但幅度弱），M5 抽象率 11.4%→32% 亦由此而来。

### 可选的修法（数据侧，未执行，待主人裁）
1. **删**那 290 行 → 只剩 194 行，够不够撑 DPO 未知；
2. **降权**（复行机制的反向，或直接抽样）；
3. **换靶**：保留那 290 条命题，把 chosen 换成语料真人诗；
4. **干净检验**：建 dpo_v5 = 只用主人票的 194 行，单开一臂对比。
按裁决"罚执行不罚特征"，**不得**改成生成时的比喻门控或负加权。

## 二、书面化漂移（句更长、标点更密、少短行、少口语）：pt8 的成分决定的

| pt8 来源 | 字数占比 | 字/行中位 | 标点/行中位 |
|---|---|---|---|
| 中文诗 zh_orig | 49.5% | 10.77 | 1.08 |
| 译诗 translated | 20.5% | 11.12 | **1.64** |
| 中文散文 prose_zh | 17.7% | **15.00**（触顶） | **2.00**（触顶） |
| 译体散文 prose_tr | 12.2% | **15.00**（触顶） | **2.00**（触顶） |

散文占 **29.9% 的字数**，且在这两项上**都顶到了度量上限**（散文本就没有诗的分行）。
再加译诗的标点密度 1.64，**一半以上的训练字符在标点密度上高于中文诗**。
M6 的 10.80 字/行、1.50 标点/行，就是这个配方的直接结果。

这一条**不是 bug，是设计后果**——散文与译本是有意加的（散文补语域、译本补句法）。
要不要收，取决于主人在 v9 里怎么投。若 M6 在真人互殴口味上吃亏，
pt9 的三阶段设计（末段回中文诗、降学习率）正是对症的解法。

## 三、更正我上一轮的一个口径

上一轮我用 base_fixed 的**有喻篇占比**（28.7%）当参照，说三臂 42–50% 是超标。
这个口径受篇幅影响（文本越长越容易含至少一个比喻），pt8 全量的有喻篇是 38.5%，
比 base_fixed 高，主要是散文拉的。
**长度无关的口径是"比喻/万字"**：base_fixed 25.5、pt8 25.8、三臂 36.9–46.3。
结论不变（三臂是训练料的 1.4–1.8 倍），但参照数字以本篇为准。

## 五、参照口径再更正一次（2026-08-30 晚，同日）

"比喻/万字"的参照值随取哪一份语料而变，三个数都列清楚，以后不再改口：

| 参照集 | 比喻/万字 |
|---|---|
| base_fixed 诗（2,005 首，我最早用的） | 25.5 |
| **pt8 实际训练料**（诗+散文+译本，模型真吃的） | **25.8** |
| **全语料诗**（corpus_stats 6,597 首，只算诗） | **30.8** |

散文的比喻密度低（中文散文 14.4、译体散文 21.9），把 pt8 的均值拉低了；
poets_v2 扩爬来的诗比喻偏高，把纯诗集的均值拉高了。

**该拿哪个比**：模型学的是 pt8，所以归因用 **25.8**；
但要问"写得像不像诗人"，该比的是纯诗的 **30.8**。
按后者，M6 的 37.9 是 **1.23 倍**——**比我上一轮说的"1.5–1.9 倍"轻**。
上一轮那个倍数是拿有喻篇占比算的，受篇幅影响，已作废。
比喻仍然超标，但幅度以本表为准。
