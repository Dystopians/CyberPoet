## 四条最硬的结论（截至 2026-09-16）

1. **语料的质 > 量**：修复损坏语料 p=0.008；语料翻倍 p=0.286；pt8 代加量 8:13、「都不要」55%——量到 pt8 见顶。
2. **罚的是执行，不是特征**：装置在含机对被罚（115:55，p<0.001，八卷合并；唯一过多重比较的口味维度），在纯人对反而受偏爱——**禁止**对修辞特征做门控或负加权。
3. **全参路线的两次败诉是数值配置**（79.56% 参数逐比特未变，11 号文档）；修正版 M7F 已跑通，同数据 dev 3.913 对 QLoRA 3.856，差的归因待同步数同学习率对照；人读在 v12 待票。
4. **六次 DPO 的参考模型都接成了裸底座**（代码/配置/日志/权重四线已证）：开局奖励 +8～+10 是既有差距，大半偏好对梯度接近 0；改回桥后短于 60 字的诗 52 → 13/198，但干预臂几乎未训，剂量验证在跑（归因报告 09-16 版）。

## 方法论纪律（同样是被验证过的）

- 大样本复验：单卷信号必须跨卷合并（「有你」16:7 塌缩、周梦蝶负倾向翻转，皆为判例）
- 预登记：面板预测写在开卷前，事后不可改（已连中 2 次）
- 可数指标只排序不做门（`filters kill the poems the owner likes`）
- 文学性判定权 100% 属于人；模型永不评审文学性
- 面板与开发集数字必须标口径：重复罚、提示模板、dev 是否含训练篇目、题面是否与训练重叠（09-16）
- 主人票的结论必须写测量范围：篇幅比、题面、卷号（09-16：机机票只覆盖篇幅比 ≤1.6）
