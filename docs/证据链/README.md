## 三条最硬的结论（截至 2026-08-29）

1. **语料的质 > 量**：修复损坏语料 p=0.008；语料翻倍 p=0.286（方向正、红利递减）。
2. **LoRA > 全参**（158 万字量级）：M4 胜 M5F 18:7，p=0.043；全参反杀 0/17。
   **归因已修正（08-29 尸检）**：不是全参方法不行，而是 `pure_bf16`+LR1e-5 让
   79.56% 的参数一个比特都没动过——全参臂等于「没训练 + 加噪」。见 11 号文档。
3. **罚的是执行，不是特征**：装置在含机对被罚（65:26，p<0.001），在纯人对反而受偏爱——
   因此**禁止**对复沓/抽象做特征级门控或负加权，治理靶点永远是执行水平。
