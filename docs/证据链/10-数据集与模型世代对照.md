## 三、模型世代（每一代 = 一次单变量实验）

| 代 | 链路 | 与上一代的**唯一**差异 | 主人裁决 |
|---|---|---|---|
| M1 | pt2 → SFT → (DPO) | 起点 | base 对一切微调臂 2:70（p=7×10⁻¹³）——微调方向有效 |
| M2 | pt3 → sft_pt3 → dpo_pt3 | 语料扩爬 | 基线臂 |
| M3 | pt5 → sft_pt5 → dpo_pt5 | **仅修复损坏洛夫** | **M3 胜 M2 22:7（p=0.008）**——语料修复显著 |
| M4 | pt6 → 纯中文退火 → sft_pt6 → dpo_pt6 | 语料 97万→158万字 + 退火 | M4 胜 M3 14:8（p=0.286，方向正未显著）；**图灵率 22% 项目最高** |
| M4b | pt6（**跳过退火**）→ … | 消融对照 | 证明分点自愈主因是语料扩容，退火是精修 |
| M5F | pt6 **全参 BAdam** → 退火 → 桥 → dpo_pt6 | **微调方式**（全参 vs LoRA）| **M4 胜 M5F 18:7（p=0.043）**；反杀 0/17 → **全参二次关闭** |
| **M5**（待训）| M4 的 SFT 桥 → **dpo_v4** | **仅偏好数据**（484 行批注重构版 vs 290 行）| 待答：您的批注能否变成梯度 |
| **M6**（待训）| **pt7** → 退火 → 桥 → **dpo_v4** | 新语料 × 新偏好（组合）| 待答：散文能否治「流水账」|

**归因图**：M6 对 M5 = 语料净效应（DPO 相同）；M5 对 M4 = 偏好净效应（语料相同）；
M6 对 M4 = 组合效应。三者同卷（v9）盲测，一次读完拿三个答案。

## 四、命名规则（避免混淆）

- `pt*` = 预训练语料版本；`dpo_train_v*` = 偏好数据版本；两者**独立编号**。
- `M*` = 模型代号，一代 = 一条完整链路（预训练→退火→SFT 桥→DPO）。
- 后缀：`b` = 消融对照臂（M4b）；`F` = 全参（M5F）。
- outputs 目录名按**段**命名（`pt6_r32`/`pt6_anneal`/`sft_pt6`/`dpo_pt6` 四段合起来才是 M4）。
