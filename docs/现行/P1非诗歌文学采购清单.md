# [P1] 非诗歌文学数据集 · 采购清单

给主人找书用。任意格式（txt/epub/mobi/pdf 均可），放到服务器任意目录后告诉我路径，
清洗管线现成。目标总量 20–40 万字（配比封顶 15–20%，课程式退火：散文在前、纯诗收尾）。

## 使用承诺（写死）
- 配比 ≤20%，A 档优先入；B 档全入；C 档视总量
- 课程式退火：散文集中在预训练前段，**最后 1–2 轮纯诗歌**收尾
- 单变量对照：加散文臂 vs 不加臂，同面板 + 你的盲测裁决
