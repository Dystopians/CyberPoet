# 训练记录与超参

## 共用设置

所有跑次都是 **QLoRA 4-bit（nf4 + 双重量化）**，`lora_target: all`（7 个模块），
**rank 32 / alpha 64 / dropout 0.05**，cosine 调度、warmup 5%、`paged_adamw_8bit`、
weight_decay 0.01、梯度裁剪 1.0、bf16 + tf32、梯度检查点、单卡 batch size 1。
基座 `Qwen/Qwen3-14B@40c069824f4251a91eefaf281ebe4c544efd3e18`，
框架 LLaMA-Factory `v0.9.5@7af9095`，template `qwen3_nothink`。

## 各跑次差异

| | v1 微调 | v2 微调 | v3 P1（计划） | 预训练 | 预训练 8 轮 | 修复版微调 |
|---|---|---|---|---|---|---|
| 阶段 | sft | sft | sft | **pt** | pt | sft（接在预训练之上） |
| 学习率 | 5e-5 | 1e-4 | 2e-5 | 5e-5 | 5e-5 | 2e-5 |
| 轮数 | 1 | 3 | 3 | 1 / 3 | 8 | 2 |
| 梯度累积 | 4 | 4 | 4 | 8 | 8 | 8 |
| 截断长度 | 4095 | 4096 | 2048 | 2048 | 2048 | **2560** |
| 序列打包 | 是（neat） | 是 | 否 | 否 | 否 | 否 |
| 数据 | 2988 | 2988 | 14 | 1591 首 / 37.3 万词元 | 同左 | 2836 修复版 |
| 步数 | 83 | 249 | — | 199 / 597 | 1592 | 710 |
| 种子 | 20260824 | 20260824 | 20260824 | 20260825 | 20260825 | 20260825 |

v1/v2 的数字取自 `training_args.bin` 与 wandb 存档，不是配置文件——
配置文件已被 v2 覆盖。

## 为什么这样选

- **预训练用 5e-5、累积 8**：语料只有 37 万词元，一轮才 199 步，累积调大让每步
  梯度更稳；学习率取 v1 的值而非 v2 的 1e-4，因为后者第 90 步就开始过拟合。
- **修复版微调用 2e-5、2 轮**：接着预训练的适配器继续训（`adapter_name_or_path`
  指向预训练产物、`create_new_adapter: false`），底子已动过一次，学习率要更低。
- **关掉序列打包**：诗很短，打包会把多首不相干的作品拼进一条 4096 序列。
- **截断提到 2560**：修复版数据最长 2317 词元，2048 会静默切掉 20 条的结尾。
- **开发集按来源诗切**：同一首诗会在三类任务里重复出现，随机切分会让同一首诗
  同时落在两边，开发损失就作不得数。

## 损失曲线

**v2 微调**（3 轮 249 步）：验证损失第 90 步触底 3.9189，之后升到第 210 步 4.0006，
末尾在 3.994–3.998 波动；训练损失同期 3.79 → 3.34。过拟合。

**最优在 epoch 2.01。** 开发集是 189 首模型没见过的诗。

## 复现命令

预训练（数据准备 → 训练）：

```bash
python scripts/pretrain/prepare_pt_data.py
CUDA_VISIBLE_DEVICES=<空闲卡> llamafactory-cli train configs/pt_qwen3_14b_qlora.yaml
```

修复微调数据 → 切分 → 接着预训练适配器微调：

```bash
python scripts/sft_repair/regen_flat_drafts.py     # 需要 GPU，约 39 分钟
python scripts/sft_repair/repair_sft_v2.py
python scripts/sft_repair/make_splits.py
CUDA_VISIBLE_DEVICES=<空闲卡> llamafactory-cli train configs/configs_sft_fixed.yaml
```

同题对照（基座 vs 适配器，不打分不排序）：

```bash
python scripts/pretrain/compare_pt.py --n 12
python scripts/pretrain/bare_prompt_test.py        # 裸提示版本
python scripts/pretrain/measure_overlap.py <生成结果.jsonl>   # 逐字重合
```
