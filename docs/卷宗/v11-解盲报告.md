## 七、这卷改写了什么判断

1. **修正版全参路线判负。** 08-29 尸检证明前两次全参败诉是数值配置事故（79.56% 参数未变）；M7F 是权重真正动了的第一版，同数据下开发集损失也不比 LoRA 差多少（3.913 对 3.856）——但主人的票是 0 比 10。「全参学得少」不是问题，「全参学出来的东西他不要」才是。全参这条线转入暂缓，除非 v12（同数据 M7 对 M7F）给出相反信号。
2. **「都不要」过半是第三次出现**（v9 M6/M4、v10b M6b/M4、本卷 M7F/M4、M7F/M6b）。三代模型的偏好训练都用的是参考模型接错的 dpo_v1，这是 09-05 归因报告已查明的共同病根；M8 的改法（参考=桥、主人票重组的 v6）就是冲着它去的。
3. **M4 仍是唯一能反杀的臂**（累计 20%）。
4. 量词泛滥（「一什么一什么」）是 M7F 独有的显性病，训练里没有任何一项专门教它——最可能来自全参阶段把语料里量词密集的诗学得过重；下一次若再训全参，出厂面板要加「量词/百字」一项。
