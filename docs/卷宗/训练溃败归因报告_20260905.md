## 1. 一页结论：现在信什么

### 已验证

1. **六次偏好训练的参考模型都是裸 Qwen3-14B**（M7F 的参考是它的全参底座 pt9F_s2）。代码、配置、日志、权重比对四条线一致。开局奖励 +8～+10 是桥与裸底座的既有差距，不是学到的：参考改对之后开局奖励 0.003。开局损失 0.95–2.66（正常 0.693）。置信 0.85。
2. **开局差距远离 0，约一半偏好对一开始就被判「已经赢了」、梯度接近 0**：按训练格式重算（09-16 当天完成）：梯度权重低于 0.05 的对 47–49%（137/136/142 之 290，三座桥），阈值 0.01→40%、0.1→52–54%、0.5→68%；平均梯度权重 0.32–0.33（正常 0.5）；开局损失 1.40–1.52（与训练日志一致）；梯度加权后正例比反例短 48–62 字（原始 −2）。初稿用带空 think 块的推理模板算出的 61% / −73 字偏大。置信 0.85。
3. **关掉重复罚，训练过的模型一半陷入整行复读，裸底座一首都没有**：SFT 桥 23/48，裸底座 0/48。复读从预训练第 1 轮就出现（9/48），第 3 轮 20/48，之后没测出继续涨。温度越低越复读（0.85 时 5.9%、0.95 时 3.8%），说明是模型分布被压尖，不是采样造成。置信 0.8。
4. **训练模板没有空 think 块、推理模板有**。新桥已统一为训练也带（只能这个方向：旧桥加上它损失几乎不变，新桥去掉它第一个字的损失飙到 30.8）。nf4 训、bf16 推的差别无害（对照曲线逐步差 ≤0.01）。置信 0.7。
5. **全参训练的 bf16 写回把小更新抹掉了**：绝对值大于 0.031 的权重 100% 没动过，动了的权重六成正好动了一个最小刻度。置信 0.72。

### 削弱后仍成立

6. **三轮偏好训练没有「背诵」，只是把反例压到底**：模型给正例的打分三轮不动（每个字约 −2.6），反例被压低 30–40 个单位；adapter 权重只变了 1.6%；1,386 首面板诗与 290 首正例没有任何 8 字以上的重合。「换 100 对数据就换一个模型」保留，它说的是数据敏感，不是背诵。
7. **dpo_v1 主要就是主人在 AI 对 AI 里投的票**：按行 88%，按实际梯度 92% 以上。31 行真人诗做正例（梯度权重不到 2%）、53 行裸底座做反例（18%，在错误参考下梯度为 0）。
8. **拽短的具体机制只到候选**：开局梯度集中在差距为负的约 80 对，其中 57 对正例更短；但同一统计在三座桥上几乎一样，而同题同种子下 dpo_v1 把 M4 的桥从 170 字拉到 220、把 M7 的桥从 252 砍到 97。更可能的机制：参考是裸底座时，训练把模型往裸底座拽（裸底座写约 124 字），加上压长反例时提前结束。
9. **7 轮预训练没有依据**：来自 08-26 把「轮数」和「提示词」绑在一起的一次盲标（22 比 10，p=0.0501），同批唯一只换轮数的 3 局是 2 轮赢 2；各链开发集损失都在第 2 轮前后见底（pt6 3.818 → 末 3.886；pt8 3.850 → 4.046）。但开发集有两处口径问题（见 4.3），「pt8 过拟合最重」撤回，轮数判决待重算。
10. **主人的票**：六卷 167 局机机决定票里，每行更长的那首赢 102 比 65（p=0.005；按模型对分层仍 p=0.002）；字数多少无倾向。**但这只在篇幅差两成以内测过**（制卷把篇幅比压在 1.6 以内，中位 1.20）；篇幅差稍大的 94 局里长的赢 58 比 36（p=0.03）；M7 那种 60–90 字的短碎病区没有任何票，v10b 那句「太短太碎」是范围外唯一的直接证据。
11. **干预实验 E**：把参考改回桥，短于 60 字的诗 52 → 13（198 首），碎行率 14.1% → 4.5%，数字全对、合并权重逐元素精确。但处理臂几乎没离开桥（同种子首行相同 83%，同配置重训两次的校准值 77%；配对字数差中位 −2）。它证明的是「参考改对 + 同超参 ⇒ 几乎没训 ⇒ 不拽短」，还没证明「参考改对 + 训到位 ⇒ 不拽短」。剂量实验（学习率 4 倍、5 轮、逐轮出面板）已挂上卡。

### 撤回

「训到背诵、似然抬几十个数量级」· 「dpo_v1 教的是别像裸底座」· 「桥越强筛选越狠（180/160/90 字）」· 「正例比反例少 4 行」· 「pt8 训 7 轮过拟合造成都不要 55%」· 「标点密度差三分之一」· 「训练数据的长度信号与主人口味相反」· 「全参 35–66% 未动因为轮到次数少」· 「dev 3.913 对 3.856 是舍入机制的直接后果」。

**新增待独立验证**（09-16 找漏，单人发现）：见第 6 节与第 8 节。

## 4. 机制

### 4.1 参考模型与训练强度（已验证 / 撤回「背诵」）

**一句话**：偏好训练拿裸底座当基准，所以一开局大半的对就被判「已经会了」，训练只在少数对上发生，而且只会把反例压低。

- 代码：LLaMA-Factory 0.9.5 对 LoRA 不建参考模型（`create_ref_model` 返回 None），训练器用 `disable_adapter()` 算参考——把 adapter 整个关掉。我们的 adapter 装着预训练+退火+SFT，一路续训、从未合并（六份日志只有「Loaded adapter」没有「Merged」；adapter 权重前后余弦 0.984–0.9998）。
- 日志：第 5 步奖励 +8.3 / +8.7 / +9.7（M4 / M6b / M7），参考改对后 0.003。第 5 步损失六次逐列：dpo_v4_m5 0.95、dpoF_pt9 1.07、dpo_pt8_v1 1.36、dpo_pt6 1.64、dpo_pt9 1.64、dpo_v5_m5b 2.66（初稿写的 3.7 是 v5 第 10 步）。
- 奖励差 9 的分解：除以 β=0.1 是 90 个自然单位没错，但其中 60–85 个在第 5 步就存在（桥与裸底座的既有差距），训练真正拉开的 30–40 个全部来自压低反例（rewards/rejected 从 +3.7 压到 0）；正例的对数似然三轮 −300.6 / −301.4 / −299.3 不动。所以不是「背诵正例」，是「压死反例」。
- 末损失改用第 3 轮全轮平均：0.245 / 0.182 / 0.325 / 0.461 / 0.459 / 0.347（M4 / M6b / M7 / M5 / M5b / M7F），末准确率 0.95 / 0.96 / 0.92 / 0.90 / 0.87 / 0.89；初稿的 0.07–0.39 是最后 40 对的单窗口数，放脚注。
- 实验 A 初稿的数字（61% 不参与、平均权重 0.28、加权后正例短 62–76 字）用的是带空 think 块的推理模板，裸底座对这 4 个 token 敏感（三对实测响应似然差 +9～+82）。**09-16 按训练格式重算（真值）**：开局奖励 +10.2 / +4.7（sft_pt6），差距均值 5.5–5.9、中位 2.2–2.8、标准差 10.5–10.8，开局损失 1.40–1.52（与训练日志前 80 对的 6.7 / 1.45 一致）；权重 <0.05 的对 137 / 136 / 142（47–49%），平均权重 0.32–0.33；开局差距为负的对 93–95；加权后正例比反例短 52 / 48 / 62 字；每 token 优势 0.90 / 0.89 / 1.03。方向不变、幅度缩两三成。M7F（参考是它自己的全参底座）同口径：权重 <0.05 的对 89（31%）、加权后短 39 字、每 token 优势 0.43——偏移约为 QLoRA 桥的一半到三分之二。差距对 token 差回归 R² 只有 0.03，主要由「反例像不像裸底座」决定（相关 +0.60）。
- 待独立验证（09-16 找漏）：DPO 没有验证集，末损失是同一 290 对第三遍的训练损失，跨轮边界一次跳落（M7 1.149 → 0.234；参考改对的臂也有 0.692 → 0.465）——末损失不能当过训判据。

### 4.5 全参（机制已验证 / 归因撤回）
