## 八、批注法典（214 条归纳）与批注如何进入材料整理

**病理词根（判死）**：流水账 / 零碎 / 儿歌化·童谣感 / 老干部体 / 鸡汤·小学生作文 / 言之无物·废话 / 量词灾难 / 语言坍缩 / 杜撰题献·不知所云 /
**太短太碎（v10b 新增，[106]）** / 语言幼稚（[v10b-1]）/ **量词泛滥「一什么一什么」（v11 四条点名，M7F 独有）** / 「老是分成一、二不是好习惯」（[v11-25]，分节标号）。
**裁决词根**：「语言」第一（语言不错/不如/幼稚/用词明显不如），「意境/场景抓人」第二，「结尾」第三，「有主旨」（[v10b-86]）为结构级。
**法则**：局部炫技不敌整体；化用≠文学性；认出诗人不改变裁决；「都不错」是险胜局不是负梯度；**流水账 ≠ 口语诗**（[v10b-5]）；**AI 胜真人仍可因短碎被弃**（[v10b-106]）。

**批注到底怎么用了（逐条对账）**
1. DPO 数据：病理点名的落选侧 ×2（dpo_v4 14 行、dpo_v5 13 行）；险胜局剔除；弃权题两侧不进 chosen。dpo_v4/v5 两条路都已判负，此后批注进 DPO 的口径改为 `build_dpo_next.py`：**chosen 必须是目标代模型自己的生成**，真人不做 chosen，「都不要」不入（v10b 合成测试 23 对）。
2. 门控与软旗：等压旗、碎行旗、量词灾难旗、LIZHI 词典来自批注；v10b 起闸门新增：首行题目回显三类剥离、西里尔字母、著名诗题包含匹配。
3. 选源规则：弱档金标不上卷；名篇不再规避（主人裁决）；**极著名诗题不做 AI 命题**（《乡愁》三臂九种子整首背诵，《黑夜的献诗》同）。
4. 臂间裁决：v9 被骂率 16%/8%/2% 定 dpo_v4；v10b「都不要」55% 定 pt8 代；主人亲测定 M5b；**v11 0:10 定修正版全参**。
5. 展示：正面批注 → 111 首「好诗牌坊」（真人 66、AI 45）；反杀 33 首过关诗册。
6. 训练方向：dpo_v4 失败 → 「chosen 在自身分布内」假说 → dpo_v5 亦败 → **09-02 面板实证：dpo_v1 套新底座拽短拽碎（M7F 125→108 / M7 193→91 字数中位）** → 下一代偏好对改用新底座自身生成。

**批注没能做到的（诚实账）**：批注给的仍主要是负梯度；正样本要靠 AI 胜局——八卷里 AI 胜局共 23 + 33 = 56 首级别的材料，正在为 M7 一代建对。
