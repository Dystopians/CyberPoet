## 八、反思：这卷改写了什么判断

1. **pt9 这一代判负，不是哪一臂的问题。** v11 判的是 M7F（全参），本卷把 M7（LoRA）和 M7Fsft（不做偏好训练）一起判了：三臂反杀 0/40，机机都不要 77%。「全参对 LoRA」这一问（本卷唯一干净的一问）答案是「都不要」——问错了层次。
2. **偏好训练不是主病根。** M7Fsft 对 M7F 88% 都不要，说明 dpo_v1 拿掉之后诗照样烂；09-05 归因把「拽短拽碎」归到参考模型接错，本卷不推翻它，但把它降为次因：把参考模型接对（M7R、M8）能治短碎，治不了「整首都是垃圾」。
3. **从 pt6 之后，每一代新预训练出来的臂都没有在你的票上超过 M4，都不要率逐代上升**（v9 25%、v10b 55%、v11 52%、v12 77%）。pt6 → pt8 → pt9 语料越扩越大，票越来越差。这不能证明是语料扩大惹的祸（同时改了桥数据、模板、训练法），但「换底座」是这四代唯一都做了的事。
4. **对 v14 的直接影响：M8 和 M8sft 的桥 sft_pt9b 就建在 pt9_s3 上**——与本卷判负的 M7 同一个预训练底座，只换了桥数据（47 家、题面）和偏好训练（参考=桥、v6 数据）。v14 因此成了一次关键检验：如果 v14 机机都不要率还在 50% 以上，那病根在 pt9 底座，桥和偏好训练怎么修都没用；如果明显掉下来，说明桥和偏好训练的修法有效。**v14 之前不再在 pt9 底座上开新训练。**
5. **下一步实验（等你点头，v14 解盲后定）：把修正后的偏好训练（参考=桥、v6 数据）套在 M4 的桥 sft_pt6 上。** 这是唯一能把「偏好训练修法」和「预训练底座」分开的单变量实验——M4 底座是你票上最好的底座，若它加上修正版偏好训练还是过半都不要，那问题就在偏好数据本身（Codex 09-21 已指出 v6 里 56% 是 v1 时代对）。
6. **少比喻第二次出现（p=0.002，含机口径）**，与「无装置」同类：AI 的比喻和装置在你眼里是套话。训练目标里可以加一条可数的：AI 生成的比喻词密度不高于语料（排序用，不做门）。
7. 韩东 5 局全「都不要」再次说明「反杀」的对手强弱不齐——v15 起标准局只拿你明确夸过的真人诗。
